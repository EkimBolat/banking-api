# 💳 Banking API

A RESTful Banking API built with **Spring Boot**, **PostgreSQL**, and **Spring Data JPA**.

## 🛠️ Tech Stack

- Java 23
- Spring Boot
- PostgreSQL
- Spring Data JPA
- Maven
